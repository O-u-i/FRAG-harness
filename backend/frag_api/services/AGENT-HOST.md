# Native Agent Host adapter

`agent_host.py` implements an original, bounded AHP 0.9.0 facade. `agent_review.py` binds explicit review actions to the existing Harness/RAG/Research flows. No provider SDK or new orchestration framework is introduced.

The installed entry `frag_api.host` validates separate installation/project/state directories, skips development `.env`, and binds only `127.0.0.1` on the launcher's unused port. The extension supplies an ephemeral bridge credential through a restricted child environment; model provider credentials remain in VS Code. `/api/agents/ahp` checks loopback client/Host and native Electron origin. Installed HTTP routes reject foreign origins and Host names; generic model-dispatch routes are blocked in favor of native-session review.

The bound project's file URI is a navigation anchor. Only that root resolves/lists in AHP, with no content, edit or terminal bridge. The reviewed HTTP selector reads explicit project files/locators; private rules/settings, generated directories and linked paths are excluded. Active-client descriptors are acknowledged with empty tool/customization registrations and are not persisted or executed.

The stable model bridge advertises available models without keys or provider URLs. A native turn records its selected model ID. Under the carrier mutation lock, `agent_review.py` temporarily binds the same selected model/configuration revision to the existing Harness/RAG/Research services, then restores their defaults. This local serialized Host uses the existing LangGraph; no additional orchestration abstraction is introduced. The model API preview is transport version 2; direct backend requests remain version 1. Legacy Pi requests are read-only and cannot recover.

v1.10.2 permits native provisional `createSession` without a model, retaining `modelId: null`. Review can read this empty session; mutation checks still require a saved task. An explicitly supplied creation model is still validated. `chat/turnStarted` must supply a current bridge model ID before task persistence; the saved session and turn record that ID. No model is selected automatically, and missing IDs never fall back to the saved carrier ID on the installed route. Creation/turn replay remains idempotent and cannot replace a saved turn's model. Catalog errors are distinguished from missing or stale model selection without exposing provider details. Creation and Send make no model calls.

`agent_sessions` stores only native identity, redacted task text, carrier state/version, selected model IDs and run links inside the existing runtime database. It does not store model request/output duplicates. Run snapshots, attempts, budgets, validation and review remain owned by `RuntimeService`. Native turn IDs are durable replay keys. Reconnect uses fresh snapshots, never event replay or model dispatch. After a process restart, an unknown client receives AHP NotFound and the native client performs a new version-negotiated initialize with its existing subscriptions.

Preparing evidence binds the current native task, session and parent run. The process-only pending record binds carrier version, turn ID, run version, source request and exact preview. Execution requires those bindings plus the matching fresh one-use token; the local pending entry is consumed before dispatch. The existing flow revalidates sources and consumes its own approval. A following stage receives a fresh carrier preview/approval only on explicit request. The existing fixed flow may retain an earlier prepared Inference attempt; it is a preparation record, not another model call. Restart clears pending approvals; unknown outcomes remain governed by existing runtime recovery.

The adapter serializes review mutations locally. Stop waits for that safe boundary and records a pause. It cannot cancel an in-flight external HTTP call. Native Send ends its AHP turn immediately, independently of AgentTurn.state, which controls Review authorization. Review cancellation or a replacement task revokes pending approval. Native snapshots contain completed receipts and derive saved output from runtime reports; no observer keeps the native turn active. Draft actions echo unchanged; only volatile process memory holds draft text and attachment descriptors for reconnect. No draft enters runtime persistence and no attachment URI is read.
