# Local evidence sources

Put supported `.md`, `.txt`, `.html`, `.pdf`, `.docx`, `.csv`, or `.xlsx` files under this folder. FRAG lists supported files but reads only the file and locators you select. Check the exact outbound preview before approving a model run. Real files are Git ignored and are never added to the synthetic RAG index automatically.

Scanned PDFs, OCR, old Office formats, macros, archives, and executables are not supported. Keep secrets out of source files when possible; automatic redaction cannot detect every private value.
